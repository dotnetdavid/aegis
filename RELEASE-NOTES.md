# Aegis v2 candidate release notes

## Included
- Tested lean UAT guidance, with `aegis2` invocation and Aegis 2 branding.
- Risk-proportionate ceremony and bounded explicit PM delegation.
- Existing stage-gate and single-master-specification controls.
- Available-model mapping rather than fixed model prescriptions.
- Complete skill metadata and all four reference guides.
- Two-step [calculator baseline](examples/calculator/calculator-create.md) and
  [percent enhancement](examples/calculator/calculator-percent.md) examples.

## Not included
- A model/effort/speed selection interface or automatic model router.
- A sandbox, tool broker, permission isolation or automated gate enforcement.
- A new runtime, dependency installer, hosted service or paid integration.
- A fresh rerun of the calculator demo; it was deferred.
- The Hermes port.

## Release status
Local candidate only. No Git commit, push, PR, hosted publication or release tag is performed by building this package. Existing v1 source and history are preserved outside the candidate. Canonical private-source instructions and the public-release allowlist must be reconciled before release; this candidate is not a substitute for that review.
